# LiteLLM Proxy Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a Twingate-private LiteLLM Proxy + Postgres infra stack at `litellm.<domain>`, deployed like Keycloak/n8n.

**Architecture:** Compose stack under `litellm/` with Traefik labels and `internal-only@file`. Proxy joins `proxy` + `internal`; Postgres stays on `internal` only. Secrets via `ENV_litellm`. Models/provider keys configured later in the UI.

**Tech Stack:** LiteLLM Proxy (`docker.litellm.ai/berriai/litellm:v1.99.0`), Postgres 16, Traefik v3, Docker Compose, GitHub Actions deploy matrix

### Task 1: LiteLLM Compose stack

**Files:**
- Create: `litellm/docker-compose.yml`
- Create: `litellm/.env.example`

**Step 1: Write compose**

Create `litellm/docker-compose.yml`:

```yaml
# LiteLLM Proxy (LLM gateway) at litellm.<domain>. Models and provider
# keys are configured in the UI after first boot (STORE_MODEL_IN_DB).
# Secrets: ENV_litellm → LITELLM_MASTER_KEY, LITELLM_SALT_KEY, LITELLM_DB_PASSWORD.
services:
  litellm:
    image: docker.litellm.ai/berriai/litellm:v1.99.0
    restart: unless-stopped
    env_file: .env
    environment:
      DATABASE_URL: postgresql://litellm:${LITELLM_DB_PASSWORD}@db:5432/litellm
      STORE_MODEL_IN_DB: "True"
    depends_on:
      db:
        condition: service_healthy
    networks: [proxy, internal]
    labels:
      traefik.enable: "true"
      traefik.http.routers.litellm.rule: Host(`litellm.${DOMAIN}`)
      traefik.http.routers.litellm.tls.certresolver: le
      traefik.http.routers.litellm.middlewares: internal-only@file
      traefik.http.services.litellm.loadbalancer.server.port: "4000"

  db:
    image: postgres:16
    restart: unless-stopped
    environment:
      POSTGRES_DB: litellm
      POSTGRES_USER: litellm
      POSTGRES_PASSWORD: ${LITELLM_DB_PASSWORD}
    volumes:
      - /opt/data/litellm-db:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U litellm"]
      interval: 5s
      timeout: 5s
      retries: 10
    networks: [internal]

networks:
  proxy:
    external: true
  internal: {}
```

**Step 2: Write .env.example**

Create `litellm/.env.example`:

```bash
# DOMAIN comes from the repo variable; the rest goes in the ENV_litellm secret.
DOMAIN=example.com

# Admin / API master key (long random; prefix sk- is conventional)
LITELLM_MASTER_KEY=sk-changeme

# Encrypts virtual keys at rest — do not rotate casually
LITELLM_SALT_KEY=changeme-long-random

# Shared by litellm DATABASE_URL and the postgres sidecar
LITELLM_DB_PASSWORD=changeme
```

**Step 3: Sanity checks (local)**

```bash
grep -n 'ports:' litellm/docker-compose.yml || true
grep -n '0.0.0.0' litellm/docker-compose.yml || true
grep -n 'internal-only@file' litellm/docker-compose.yml
grep -n 'ghcr.io' litellm/docker-compose.yml || true
```

Expected: no `ports:` / `0.0.0.0` / `ghcr.io`; middleware label present.

**Step 4: Commit**

```bash
git add litellm/docker-compose.yml litellm/.env.example
git commit -m "Add LiteLLM proxy Compose stack behind Traefik."
```

**Step 4: Verify**

```bash

ssh deploy@VPS 'docker compose -f /opt/infra/litellm/docker-compose.yml ps'
ssh deploy@VPS 'grep -n ports /opt/infra/litellm/docker-compose.yml || true'

# Twingate OFF — expect 403
curl -sI "https://litellm.$DOMAIN" | head -1

# Twingate ON — expect 200 / app UI
curl -sI "https://litellm.$DOMAIN" | head -1
```

Open UI over Twingate; sign in with master key; add a model when ready.

| Check | Expected |
|---|---|
| Twingate off → `https://litellm.$DOMAIN` | 403 |
| Twingate on → UI | reachable |
| Compose `ps` | litellm + db running/healthy |
| Host published ports on litellm stack | none |

**Rollback:** `workflow_dispatch` previous SHA for stack `litellm`, or remove Resource and stop stack:

```bash
ssh deploy@VPS 'cd /opt/infra/litellm && docker compose down'
```

Data under `/opt/data/litellm-db` is retained unless intentionally deleted.
